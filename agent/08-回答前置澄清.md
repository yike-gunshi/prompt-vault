# 回答前置澄清（Reddit 钢人原帖中译）

> 双向钢人论证的源头版本：不让模型直接回答，先逼它暴露你的隐含假设和缺口，再用一个关键问题对齐真实目标。问题还没成型、需要先挖需求时用它。

## Prompt 原文

```text
请先不要回答我的问题。在给出答案之前，请先完成以下分析:1、指出我在这个问题中没有明确说出、但已经默认成立的假设;2、告诉我还缺少哪些关键信息，以及这些信息可能如何改变你的答案;3、指出人们在处理这类问题时最常犯的一个错误。然后，请只向我提出一个最关键的问题。这个问题应该能够帮助你理解我的真实目标和具体情况，让最终答案真正对我有用，而不是一份谁都能套用的通用建议。等我回答以后，你再给出最终输出。我的问题是:[粘贴你的问题]
```
