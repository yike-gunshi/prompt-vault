# 双向钢人论证

> 想法已经成型、需要辩证检验时用：AI 同时把「支持你」和「反对你」两边都钢人强化到最强，谄媚互相抵消，剩下的就是真正的分歧；最后只问你一个关键问题，逼出明确判断和行动。

## Prompt 原文

**原版（卡兹克）**

```text
先别急着回答，也别默认我已经把问题想清楚。
请先对这个问题做一次详细思考的“双向钢人论证”：
1.用最完整、最有力的方式，重述我真正想解决的问题。
2.使用钢人论证法分别给出支持我当前想法、以及反对它的最强论证。
3.找出双方真正的分歧，以及最可能改变结论的关键变量。
4.只问我一个最关键的问题。
等我回答后，再给出明确判断、理由和下一步行动。

我的问题是：
[粘贴你的问题]
```

**变体：评论区优化版（硅基X档案）**

```text
先别急着回答，也别默认我已经把问题想清楚，更别为了让我舒服而弱化反对意见。
请先对这个问题做一次详细的"双向钢人论证"：
重述问题：用最完整、最有力的方式，重述我真正想解决的问题——不是字面意思，而是背后的真实困惑。
如果我问错了问题，请指出。
双向钢人：
支持方：假设我是对的，给出支持我当前想法的最强论证。穷尽所有有力的理由，不要遗漏。
反对方：假设我是错的，给出反对我当前想法的最强论证。不留情面，不手下留情——你的任务不是安慰我，而是帮我看清盲区。
分歧与翻转：找出双方真正的分歧点。然后回答：如果只能改变一个假设就能翻转最终结论，那个假设是什么？
关键一问：只问我一个最关键的问题——那个最能帮我厘清思路、最可能改变结论走向的问题。等我回答后，再给出你的明确判断、理由和下一步行动建议。
我的问题是：
```

## 使用备注

- 作者的四步设计思路：① 重写问题——把"嘴上问的"和"真正想解决的"分开；② 双向强化——两边都不能靠歪曲对方取胜，真冲突才显露；③ 找决定结论的一两个关键变量；④ 逼 AI 给明确判断和行动，不许不粘锅。
- 适用边界（评论区共识）：想法已成型、要辩证检验 → 用本条；问题还没成型、要挖需求 → 用 grill me / 前置澄清类（见 [clarify-before-answer](08-回答前置澄清.md)）。
- 简单、明确、低风险的问题不适合走这套流程，弊大于利（评论区 陆子男）。
