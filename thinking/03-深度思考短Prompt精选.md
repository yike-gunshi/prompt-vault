# 深度思考短 Prompt 精选（评论区）

> 《一个极度实用的深度思考Prompt》评论区里被点赞较多的四条同类 prompt，各有侧重：执行前澄清、结论质检、渐进追问、带准入判断的完整流程。

## Prompt 原文

**执行前先澄清（评论区 💫Koi）**

```text
执行我的任务前，请先不要急着输出结果。
请你先识别我这个需求里所有模糊、缺失、可能影响结果的信息，并列出问题向我确认；等我补充完关键信息之后，你再正式开始执行。
如果你必须先做假设，请明确告诉我你做了哪些假设，不要自己偷偷脑补。
```

**结论五要素带置信度（评论区 💫Koi）**

```text
最终结论请包括:
1.这个想法值得做、需要改，还是应该放弃;
2.最大风险是什么;
3.最缺的关键证据是什么;
4.今天可以执行的最小一步是什么;
5.你的置信度是多少。
记住:准确性高干让我满意。不要无脑夸我，不要顺着我说。不确定就说不确定，不要编答案。
```

（"高干"为原文笔误，疑为"高于"，逐字保留。）

**95% 确信前逐一追问（评论区 涌上）**

```text
在给出最终方案前，先向我提问。要求：一次只问一个问题，根据我的回答继续追问，直到你有95%的信心完全理解我的真实需求和目标，再给出最终方案
```

**条件触发完整流程（评论区 Vincent）**

```text
先别急着回答，也别默认我已经把问题想清楚。先判要不要走这套流程如果这个问题低风险、可逆、需求已经明确 → 直接告诉我"这个不用走流程"，然后正常回答。只有满足以下任一条才继续：影响面大、不可逆、返工成本按周算、我自己都没想清楚。
重述与纠偏用最完整的方式重述我真正想解决的问题——不是字面意思，是背后的真实困惑。如果我问错了问题，直接说，并告诉我应该问什么。挖出隐含假设列出我没说但已经默认成立的假设。标出哪些假设一旦不成立，结论就得推翻。
给出最强可行方案（不是正反二元）给 2-4 个方向，不要强行分成支持和反对两派——那样会挤掉可能最优的第三条路。每个方向说清：最强论证（必须基于可验证事实；属于推测的明确标注）什么条件下它是最优解代价、风险、我需要付出什么约束：不为了凑数造弱方案。不把薄弱想法包装得很精致——逻辑完整但事实悬空的方案比没有方案更危险。
找关键分歧各方案真正的分歧点在哪里？然后回答一个问题：如果只能改变一个假设就能翻转最终结论，那个假设是什么？
缺什么信息你能自己查或验证的 → 直接去查，别拿来问我只有我知道、且会改变结论的 → 问我，一次只问最关键的那一个如果信息已经够了，跳过这步直接给结论。
结论信息够了才给。包含：值得做 / 需要改 / 应该放弃最大风险是什么最缺的关键证据是什么今天就能执行的最小一步置信度（百分比 + 凭什么）
```

（Vincent 版换行在公众号评论区显示中部分丢失，按粘贴原样保留。）
