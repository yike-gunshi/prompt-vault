# B 端原型设计系统 Prompt 手册

> 一整套喂给 AI 原型工具（Readdy、Uizard、Galileo、Figma AI、Framer AI 等）的 B 端页面 prompt 模板库：先用通用框架生成低保真，再拼微指令加细节，最后用评审与迭代 prompt 打磨。

## Prompt 原文

**通用 Prompt 框架（可一键改装）**——用途：任意 B 端页面/流程原型，将【花括号】替换成你的内容

```text
你是一名资深 B 端产品与 UX 设计师。请为【{产品/平台名称}】生成【{低保真线框 | 中保真 | 高保真 UI}】原型。

目标：{一句话描述业务目标，例如「让运营高效筛选 badcase 并批量处理」}
用户：{角色/权限，例如「数据分析师、算法同学、运营同学；RBAC 三种角色」}

信息架构：
- 页面类型：{仪表盘 | 列表 | 详情 | 表单 | 向导 | 工作流画布 | 报表}
- 关键模块：{模块1}、{模块2}、{模块3}
- 关键动作：{创建/导入/筛选/批量操作/导出/回滚}

布局与栅格：桌面端优先，容器宽 1440px，12 列栅格，基准间距 8/12/16。页头-内容-页脚三级层次；面包屑+标题+操作区。

风格与品牌（偏字节系）：
- 主色淡蓝（如 #3A84FF 附近）、灰阶中性、轻阴影、圆角 12-16px；信息密度「中-偏紧凑」。
- 常用组件风格接近 Ant Design。

组件清单（按从上到下）：
- {筛选区：搜索输入、选择器、标签筛选、时间范围、保存视图按钮}
- {数据区：表格/图表/卡片；列定义、排序、固定列、分页}
- {侧栏/抽屉：用于详情/编辑}
- {全局反馈：空/加载/错误/权限不足}

数据样例：使用真实感占位数据（中文姓名、企业名、数据集名、UTC 时间、ID）。

可访问性与国际化：所有交互有键盘操作说明，文案可切换中英文（先用中文）。

输出要求：
- 先给 2-3 个布局备选，再选一版细化。
- 标注交互（悬停、选中、禁用、批量、多选、快捷键）。
- 命名图层：`模块_功能_状态`，导出为可编辑分组。

负向约束：不要花哨插画，不要过多装饰，不要模糊文本。
```

**一句话速成：仪表盘（运营/技术）**

```text
生成一个中保真 B 端仪表盘：头部含筛选与时间选择，主区 2x2 卡片展示 KPI（今日/7天/30天），附折线+柱状组合图；右侧放最近动态列表，底部放 Top N 排行表；支持保存视图。
```

**一句话速成：列表+筛选+批量操作**

```text
为资源管理创建紧凑型列表页：顶部多条件筛选（关键字、状态、标签、时间范围、负责人），表格含固定选择列、名称、状态、更新时间、负责人、操作；支持多选、批量启停、导出 CSV；提供空/加载/错误状态。
```

**一句话速成：详情+侧栏编辑**

```text
生成资源详情页：左主右侧栏。主区含概览卡片、关键属性、活动日志、关联对象表；右侧栏为可折叠的表单编辑区（即时校验、保存/取消、变更高亮）。
```

**一句话速成：创建向导（Wizard）**

```text
生成四步向导：1) 选择模板 2) 填写基础信息 3) 参数配置 4) 确认与创建；顶部进度条，底部上一步/下一步/保存草稿；校验与错误提示清晰。
```

**一句话速成：工作流画布（节点式）**

```text
生成节点式工作流画布：左侧节点库（输入/处理/评测/导出），中间可连线画布，右侧属性面板；支持吸附网格、分组、缩放、对齐线、节点验证、运行预检查。
```

**一句话速成：权限矩阵（RBAC）**

```text
生成权限矩阵页：左列为资源类型，上方为角色；单元格为开关/粒度下拉；支持批量授权、搜索资源、导出权限快照、变更审计。
```

**一句话速成：报表构建器**

```text
生成自助报表构建器：左侧维度/指标区，中间拖拽画布，顶部图表类型切换（折线/柱状/饼/表格），右侧查询与样式面板；支持保存、分享、导出 PNG/CSV。
```

**LLM 提效/评测平台专用：数据导入向导（含校验）**

```text
为「LLM 提效平台」生成数据导入四步向导：1) 选择数据类型（标注/评测/业务） 2) 上传文件或连接数据源（CSV/飞书表） 3) 字段映射与预览（高亮异常） 4) 校验与导入；提供错误收集下载、去重选项、导入进度条与失败重试。
```

**LLM 提效/评测平台专用：数据集管理（版本+标签）**

```text
生成数据集列表页：顶部筛选（数据类型、标签、更新时间、创建人），表格含名称、版本、规模、标签、通过率、更新时间、操作；支持版本对比、回滚、导出；空/加载/错误状态完整。
```

**LLM 提效/评测平台专用：标签管理（多层级）**

```text
生成标签管理页：左侧树（标签组/标签），右侧列表（样本数、最近使用、创建人），支持新建/合并/重命名/清理未使用标签；提供批量打标抽屉。
```

**LLM 提效/评测平台专用：Badcase 富集与处置**

```text
生成 badcase 富集页：顶部按规则筛选（模型/场景/标签/错误类型），中区卡片或表格列表，右侧详情抽屉展示原问、答案、参考、指标、差异对比；支持一键加入回炉训练集、提交缺陷工单、指派负责人。
```

**LLM 提效/评测平台专用：Workflow/Agent 编排**

```text
生成 LLM 工作流编排画布：节点含「检索」「重写」「调用模型」「评测」「过滤」「写入仓库」；右侧属性面板配置超参（温度、top_p）、路由条件、重试与回退；支持分支、子流程、模板化与版本管理。
```

**LLM 提效/评测平台专用：任务队列与运行监控**

```text
生成任务中心：页签为「排队中/运行中/已完成/失败」，表格含任务 ID、工作流、优先级、耗时、重试次数、触发人；顶部有暂停/恢复/重试/终止；提供实时日志与资源用量（QPS、延迟）。
```

**LLM 提效/评测平台专用：评测配置表单**

```text
生成评测配置表单：选择数据集、多模型对比、指标（BLEU/ROUGE/BERTScore/自定义打分）、采样比例、预算上限；右侧预估耗时与 tokens 成本；校验与默认值完整。
```

**LLM 提效/评测平台专用：评测结果对比（表+图）**

```text
生成评测结果页：顶部模型与数据集切换，中区双列布局：左侧雷达图/柱状图/趋势线，右侧明细表（按指标排序、显著性标记）；支持导出报告、固定基线、差异高亮。
```

**LLM 提效/评测平台专用：知识库管理（RAG）**

```text
生成知识库管理页：文档列表（标题、来源、分片数、索引状态、上次同步）、右侧文档预览；提供重建索引、分片策略、embedding 维度设置、同步日志。
```

**LLM 提效/评测平台专用：平台总览 KPI**

```text
生成平台总览仪表盘：关键 KPI（请求量、首 token 延迟、成功率、评测覆盖率、badcase 下降率），附 7/30 天对比；下方是告警与变更日志时间线。
```

**细节控制微指令库（按需拼接，把短语直接追加到主 Prompt 尾部）**

```text
- 密度：「信息密度偏紧凑/表格行高 40px、卡片内边距 16」
- 表格：「首列多选、名称列左对齐、数值右对齐、最后一列操作固定、支持列拖拽与显示/隐藏、空单元有 `—` 占位」
- 表单：「两列表单、标签右对齐、字段说明以 ? 提示、错误提示内联显示、必填星号、回车提交」
- 筛选：「可保存筛选视图、最近使用、支持快捷键 `/` 聚焦搜索」
- 批量操作：「多选后显示悬浮操作条（批量启停/导出/指派）」
- 状态：「提供空/加载骨架/错误/无权限四套状态；错误建议具体修复动作」
- 响应式：「≥1280px 两列，<1280px 变单列，表格横向滚动，主要操作固定顶部」
- 国际化：「文案用句柄形式，预留翻译长度」
- 可访问性：「Tab 顺序/焦点清晰，按钮有 aria-label」
- 真实数据：「生成 10 行中文业务数据，字段含名称、ID、状态（启用/停用）、更新时间（ISO）、负责人（中文名）」
```

**评审与迭代：多方案生成**

```text
为同一需求生成 3 个布局变体：信息密度（紧凑/中/舒适），导航形式（侧边栏/顶栏），请用缩略图预览并给出选择理由。
```

**评审与迭代：可用性检查**

```text
按 Nielsen 启发式对当前原型做自检：可见性、系统与现实世界匹配、用户控制、错误防止、一致性、识别优于回忆、灵活性与效率、审美与极简、帮助与文档；指出 5 个最优先问题并给改进方案。
```

**评审与迭代：任务走查**

```text
以「新用户第一次导入数据并完成评测」为用例，从进入平台到看到结果的 7 步操作路径，标注每步主要控件、预期耗时、潜在阻力点与备选路径。
```

**评审与迭代：性能与可维护性**

```text
检查页面是否存在性能风险（表格列过多、首屏阻塞、图表过重），给出骨架屏、分页、虚拟滚动、延迟加载等改造建议。
```

**字节风格 & Tailwind 约束（可选）**

```text
样式基调：扁平、淡蓝主色、弱阴影、对比清晰。
栅格：12 列，容器宽 1440，间距 8/12/16。
圆角：按钮/卡片 12-16px，输入框 10-12px。
排版：标题 20/24/28，正文 14/16，行高 1.5。
图表：折线用于趋势，柱状用于对比，饼图慎用；图例可切换。
Tailwind 令牌（示例）：`text-slate-700 bg-white rounded-2xl shadow-sm border border-slate-200 accent-blue-500`。
```

**输出规范与交付**

```text
- 先产出 Site Map/Flow，再出页面线框。
- Frame 命名：`[页面]_[模块]_[状态]`，组件命名：`[原子]_[变体]`。
- 每页附「交互说明」注释层。
- 导出：可编辑分组 + 资源标注（尺寸/间距/状态）。
```

**负向提示（统一约束）**

```text
不要模糊文案与图片占位；不要使用艳丽渐变或复杂玻璃拟态；不要隐藏关键操作在三级菜单；不要出现中文与英文混排不一致的间距；不要超出 1440px 容器宽度。
```

**复用模板 A：列表+筛选**

```text
为【{平台名}】生成【中保真】的资源列表页，信息密度偏紧凑。顶部提供：{关键字输入、状态选择、标签选择、时间范围、保存视图}。表格列：{选择框、名称、状态、更新时间、负责人、操作}；支持多选批量；提供空/加载/错误状态。样式偏字节风格，主色淡蓝；12 列栅格，容器宽 1440。输出 2 个布局变体并说明取舍理由。
```

**复用模板 B：工作流画布**

```text
生成【节点式工作流画布】原型：左侧节点库（{节点清单}），中间可连线画布（吸附网格、缩放、对齐线），右侧属性面板（{可配置项}）；提供运行预检查与错误标注；导出可编辑分组。
```

**复用模板 C：创建向导**

```text
生成 4 步创建向导：1) {选择模板} 2) {基础信息} 3) {参数配置} 4) {确认创建}；提供保存草稿、字段校验、错误集中提示；桌面端优先。
```

**复用模板 D：对比报告**

```text
生成对比报告页：左侧选择对比对象，右侧上方为雷达/柱状图，下方为明细表；支持固定基线、显著性标记、导出 PNG/CSV；提供空/加载/错误状态。
```

## 使用备注

- 手册用法：把模板复制到 Readdy、Uizard、Galileo、Figma AI、Framer AI 等工具里即可。先用「通用框架」生成低保真，再用「微指令库」逐步加细节，最后用「评审与迭代」反复打磨。
- 小贴士：把「通用框架 + 页面类型 + 微指令 + 负向提示」拼成一个长 Prompt，复用性最高；生成后立刻用「评审与迭代」提示进行二轮优化。
